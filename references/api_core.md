# COMSOL Core API Reference (COMSOL 6.4)

Structured API reference extracted from `COMSOL_ProgrammingReferenceManual.pdf` (COMSOL 6.4, `D:\ENV\COMSOL64\Multiphysics\doc\pdf\COMSOL_Multiphysics\`).

Feature type strings are **exactly** as passed to `create()`. They are capitalized and case-sensitive (e.g. `Rectangle`, not `rectangle`). The same strings work in the mph Python binding (`model.java.component(...).geom(...).create('r1','Rectangle')`), in MPh's native API, and in COMSOL's Java/MATLAB APIs.

## 0. General API Patterns

### 0.1 Object hierarchy

```
model
├── model.component(ctag)          # Model component container
│   ├── .geom(gtag)                # Geometry sequences
│   ├── .mesh(mtag)                # Meshing sequences
│   ├── .physics(phystag)          # Physics interfaces
│   ├── .material(mat)             # Materials
│   ├── .cpl(tag)                  # Nonlocal couplings / component couplings
│   ├── .selection(stag)           # Named selections (component level)
│   ├── .func(tag)                 # Functions (component level)
│   ├── .variable(), .coordSystem(), .pair(), .view()
├── model.param()                  # Global parameters
├── model.func()                   # Global functions
├── model.selection()              # Global selections
├── model.study()                  # Studies + study steps
├── model.sol()                    # Solver sequences (generated by studies)
├── model.result()                 # Plot groups, datasets, derived values, exports, tables
│   ├── .dataset().create(dtag, dtype)
│   ├── .numerical().create(ntag, ntype)   # Derived values
│   ├── .export().create(etag, [pgtag], etype)
│   ├── .table().create(ttag)
│   └── (pgtag).create(ftag, ftype)        # Plots inside a plot group
└── model.batch(), model.solverEvent(), model.methodCall()
```

### 0.2 Core methods

| Method | Purpose |
|---|---|
| `create(tag, type)` | Add a feature of given type; tag is arbitrary identifier |
| `set(property, value)` | Set a property (value may be scalar, string, or array) |
| `setIndex(property, value, idx1[, idx2])` | Set element of an array property (0-based indices) |
| `selection().geom(dim).set([ents])` | Set entity selection by dimension |
| `selection().set([ents])` | Set selection (dimension inferred) |
| `selection().named(tag)` | Reference a named selection |
| `selection().init(dim)` / `.init()` | Initialize a selection for entity dimension |
| `run([tag])` | Build/evaluate (geometry, mesh) or plot/evaluate (results) |
| `label('...')` | Set display label |
| `getType(property)` | Query property value |
| `active(bool)` / `isActive()` | Enable/disable feature |
| `remove(tag)`, `move(tag, pos)` | Delete/move feature in sequence |
| `current()` | Tag of current (last-built) feature |
| `name('...')` | Rename a feature (e.g. `feature('fin').name('Form Assembly')`) |

Numeric properties accept either numbers or string expressions that may reference `model.param()` parameters, e.g. `set('hmax', '5[nm]')`.

### 0.3 Dimension conventions (CRITICAL)

| Context | dim | Meaning |
|---|---|---|
| `geom().create(tag, sDim)` | 1 / 2 / 3 | Space dimension of geometry (1D, 2D, 3D) |
| `selection().geom(dim)` (mesh, physics) | 0 / 1 / 2 / 3 | 0=vertices, 1=edges (2D boundary), 2=faces/domains-in-2D, 3=domains (3D) |
| `selection().init(dim)` (geometry) | 0 / 1 / 2 / 3 | 0=vertices, 1=edges, 2=faces (3D boundaries), 3=domains (3D) |
| `entitydim` property (selection features) | -1 / 0 / 1 / 2 / 3 | -1=Objects, 0=vertices, 1=edges, 2=faces/boundaries, 3=domains |
| `result().create(pgtag, dim)` | 1 / 2 / 3 | Plot group dimension |
| Mesh sequence creation | — | `mesh().create(tag, geomtag)` binds mesh to a geometry |

Quick reference: `1=boundary/edge (2D), 2=domain (2D)/boundary (3D), 3=domain (3D)`.

## 1. GEOMETRY API

### 1.1 Geometry sequence

```java
// Java
model.component("comp1").geom().create("geom1", 3);   // sDim: 1, 2, or 3
GeomSequence g = model.component("comp1").geom("geom1");
g.create("r1", "Rectangle");
g.feature("r1").set("size", "0.1 0.2");
g.run();                          // build all
g.run("r1");                      // build up to feature r1
```

```python
# mph (Python)
comp = model.java.component('comp1')
g = comp.geom().create('geom1', 3)
g.create('r1', 'Rectangle')
g.feature('r1').set('size', ['0.1[m]', '0.2[m]'])
g.run()
```

Methods: `geom().create(tag, sDim)`, `geom(tag).create(ftag, ftype)`, `geom(tag).feature(ftag).set(p, v)`, `geom(tag).run()`, `geom(tag).getNDomains()`, `getNBoundaries()`, `getNEdges()`, `getNVertices()`, `geom(tag).lengthUnit('nm')`, `geom(tag).axisymmetric(True)` (2D).

### 1.2 Finalize — Form Union / Form Assembly

Every geometry sequence ends with a Finalize feature. Only tag `fin` is allowed.

| Type string | Purpose |
|---|---|
| `FormUnion` | Combine all objects into a single union object (default) |
| `FormAssembly` | Keep objects separate, create identity/contact pairs |

```java
g.create("fin", "FormUnion");
g.feature("fin").set("action", "union");        // union | assembly
g.feature("fin").set("imprint", true);          // imprint (assembly)
g.feature("fin").set("createpairs", true);      // create pairs (assembly)
g.feature("fin").set("pairtype", "identity");   // identity | contact
g.feature("fin").set("repairtol", "1e-6");
```

### 1.5 Boolean operations

```java
g.create("uni1", "Union");
g.create("int1", "Intersection");
g.create("dif1", "Difference");
g.create("co1", "Compose");
g.feature("uni1").selection("input").set(new String[]{"r1", "c1"});  // objects to combine
```

| Type string | Purpose | Key properties |
|---|---|---|
| `Union` | Combine objects (Boolean add) | `keep` on\|off (keep input), `repairtol` = 1e-6, `absrepairtol` = 1e-6, `repairtoltype` auto\|relative\|absolute, `color` |
| `Intersection` | Common part of objects | same |
| `Difference` | First object minus others | `input` = objects to subtract from, `input2`-style second selection, `keep` |
| `Compose` | Combine with a set formula | `formula` string, e.g. `"sq1+sq2-c1"`; `input` selection |

Selection assignment:
```python
g.feature('uni1').selection('input').set(['r1', 'c1'])      # by object tag
g.feature('dif1').selection('input').init(2).set('blk1', [1])  # entities: dim 2, object blk1
g.feature('co1').set('formula', 'sq1+sq2-c1')
```
`keep` property: if on, input objects are kept (default off for operations).

### 1.7 2D-to-3D features

| Type string | Key set() properties |
|---|---|
| `WorkPlane` | `planetype` = quick\|faceparallel\|edgeparallel\|edgeangle\|circleperpendicular\|normal\|vertices\|coordinates\|transformed; `quickplane` = xy\|yz\|zx\|yx\|zy\|xz; `unite` on\|off; 2D features drawn inside via `g.feature('wp1').geom().create('r1','Rectangle')` |
| `Extrude` | `distance` double or double[] (per layer); `displ` double[nd][2]; `extrudefrom` = workplane\|faces\|edges\|vertices; `includeinput` bool = true; `crossfaces` on\|off = on; `workplane`; selections: `input`, `inputface`, `inputedge`, `inputvertex` |
| `Revolve` | `angle1` = 0; `angle2` = 0; `angtype` = specang\|full; `axistype` = 2d\|3d\|edge; `axis` double[2] = {0,1} (2D local); `axis3` double[3] = {0,1,0}; `pos`; `revolvefrom` = workplane\|faces\|edges\|vertices; selections: `input`, `inputface`, `inputedge`, `inputvertex`, `edge` |
| `Sweep` | `enttosweep` selection (init with dim 2/1/0); `edge` selection (spine); `diredge`; `includeinput`; `includefinal`; `crossfaces`; `workplane` |

```python
# Work plane with 2D geometry then extrude
g.create('wp1', 'WorkPlane')
g.feature('wp1').set('planetype', 'quick')
g.feature('wp1').set('quickplane', 'xy')
g.feature('wp1').geom().create('r1', 'Rectangle')     # 2D geometry inside work plane
g.feature('wp1').geom().feature('r1').set('size', ['1[mm]', '1[mm]'])
g.create('ext1', 'Extrude')
g.feature('ext1').set('distance', '2[mm]')
g.run()
```

### 1.8 Geometry selection features

Created in the geometry sequence; output is a named selection usable in physics (tag `geom1_sel1`).

| Type string | Key set() properties |
|---|---|
| `ExplicitSelection` (alias `Selection`) | `selection` (via `feature(ftag).selection('selection').init(dim).set(obj, entities)`); `groupcontang` on\|off; `angletol` = 5; `selkeep` on\|off = on; `selshow` on\|off = on; `entitydim` |
| `BoxSelection` | `xmin` = -inf, `xmax` = inf, `ymin` = -inf, `ymax` = inf, `zmin` = -inf, `zmax` = inf (all double); `condition` = intersects\|inside\|somevertex\|allvertices; `entitydim` = -1\|0\|1\|2\|3; `inputent` = all\|selections; `input` String[]; `groupcontang`; `angletol` = 5 |
| `BallSelection` | `posx`, `posy`, `posz` = 0; `r` = 0; `condition`; `entitydim` |
| `CylinderSelection` | `posx`, `posy`, `posz` = 0; `r` = 0; `h` = 1; `angle1` = 0; `angle2` = 360; `axis`; `axistype`; `condition`; `entitydim` |
| `DiskSelection` | `posx`, `posy`, `posz`; `r`; `normal`/`axistype`; `condition`; `entitydim` |
| `UnionSelection` | `add` String[] (tags of input selections); `entitydim` |
| `IntersectionSelection` | `add` String[]; `entitydim` |
| `DifferenceSelection` | `add` String[], `subtract` String[]; `entitydim` |
| `ComplementSelection` | `entitydim` (all entities not in input selections) |
| `AdjacentSelection` | adjacency expansion of an input selection |
| `LogicalExpressionSelection` | expression-based selection |
| `CumulativeSelection` | collects contributions via `contributeto` |

```python
g.create('boxsel1', 'BoxSelection')
g.feature('boxsel1').set('xmin', '0.4[m]')
g.feature('boxsel1').set('xmax', '0.6[m]')
g.feature('boxsel1').set('entitydim', 2)      # 2 = faces/boundaries (3D)
g.run()
# then use in physics:  solid.selection().named('geom1_boxsel1')
```

`condition` semantics: `intersects` = all entities intersecting the shape; `inside` = completely inside; `somevertex` = at least one adjacent vertex inside; `allvertices` = all adjacent vertices inside.

## 2. MESH API

### 2.1 Meshing sequence

```java
MeshSequence m = model.component("comp1").mesh().create("mesh1", "geom1");
m.create("ftri1", "FreeTri");
m.run();
```

mesh = comp.mesh().create('mesh1', 'geom1')   # mph: create(tag, geomtag)

### 2.3 Mesh attribute features (subfeatures of element features, or standalone)

| Type string | Key set() properties | Defaults |
|---|---|---|
| `Size` | `hauto` (1..9 or any nonnegative scalar; 1=finest, 5=Normal, 9=coarsest); `custom` on\|off; `hmax` (geometry dependent); `hmin`; `hcurve` = 0.3\|0.6; `hgrad` = 1.3\|1.5 (element growth rate); `hnarrow` = 0.5; `table` = cfd\|default\|plasma\|semi\|coarseadaptation\|timeexplicitwave | hauto=5 |
| `SizeExpression` | `sizeexpr` string; `gridtype` = cellresolution\|cellsize; `numcell` = 25; `hmeshgrad` = 1.4; `cellsize`; `exprtype` = size\|error; `evaltype` = grid\|solution\|initialexpression | |
| `Distribution` | `type` = number\|explicit\|predefined; `numelem` = 5 (number mode); `equidistant` on\|off; `explicit` array (increasing from 0); distribution parameters (ratio, reverse...) | type=number |
| `BndLayerProp` | `blnlayers` = 8 (number of layers); `blstretch` = 1.2 (stretching factor); `inittype` = blhminfact\|blhmin\|blhtot; `blhminfact` = 1; `blhmin` (first layer thickness); `blhtot` (total thickness) | inittype=blhminfact |
| `CornerRefinement` | corner mesh refinement (on faces) | |
| `EdgeMap` / `OnePointMap` / `TwoPointMap` | edge mapping for swept/mapped meshes | |
| `EdgeGroup` | group edges | |

```python
mesh.create('ftet1', 'FreeTet')
mesh.feature('ftet1').selection().geom(3).set([1])          # 3D domain 1
sz = mesh.feature('ftet1').create('size1', 'Size')          # attribute subfeature
sz.selection().geom(3).set([1])
sz.set('custom', 'on')
sz.set('hmax', '2[mm]')
sz.set('hmin', '0.1[mm]')
mesh.create('bl1', 'BndLayer')
mesh.feature('bl1').selection().geom(2).set([1, 2])         # boundaries 1,2
blp = mesh.feature('bl1').create('blp', 'BndLayerProp')
blp.selection().set([1, 2])                                 # boundary-layer location
blp.set('blnlayers', 5)
blp.set('blhmin', '0.05[mm]')
blp.set('blstretch', '1.2')
mesh.run()
```

Typical mesh sequence: `Size` (global hmax/hmin) → `FreeTet`/`FreeTri` (+ nested `Size`, `SizeExpression`, `Distribution`) → `BndLayer` (with `BndLayerProp`) → `Sweep`/`Map` for structured regions → `run()`.

## 3. STUDY API

### 3.1 Study sequence and study steps

```java
model.study().create("std1");
model.study("std1").create("stat", "Stationary");   // study step
model.study("std1").run();                          // compute
```

```python
std = model.java.study().create('std1')
std.create('stat', 'Stationary')
model.solve()          # mph: solves all studies (recommended)
```

### 3.2 Study step types (model.study(tag).create(stepTag, type))

| Type string | GUI name | Key set() properties |
|---|---|---|

| `Ball` | entities inside/intersecting a ball | `posx`/`posy`/`posz` = 0; `r` = 0; `condition` = intersects\|inside\|somevertex\|allvertices; `entitydim` = 0..3 |
| `Box` | entities inside/intersecting a box | `xmin`=-inf, `xmax`=inf, `ymin`, `ymax`, `zmin`, `zmax`; `condition`; `entitydim` |
| `Cylinder` | entities in a cylinder | `posx/y/z`, `r`, `h`, `axis`/`axistype`, `condition`, `entitydim` |
| `Disk` | entities in a disk | `posx/y/z`, `r`, normal, `condition`, `entitydim` |
| `LogicalExpression` | expression-based | `expr` |

Named selections are referenced anywhere via `selection().named(tag)` or directly by tag string in properties.

## 7. Quick Reference — Common Full Workflows

### 7.1 2D axisymmetric solid-mechanics model (mph)

```python
import mph
client = mph.start(cores=4)
model = client.create('demo')
jm = model.java
comp = jm.component().create('comp1', True)
geom = comp.geom().create('geom1', 2)
geom.axisymmetric(True)
geom.lengthUnit('mm')

g = comp.geom('geom1')
g.create('r1', 'Rectangle');  g.feature('r1').set('size', ['10[mm]', '1[mm]'])
g.create('fin', 'FormUnion'); g.run()

# named selection for top boundary
sel = comp.selection().create('top', 'Box')
sel.geom('geom1', 1);  sel.set('ymin', '0.999[mm]'); sel.set('ymax', '1.001[mm]')
sel.set('condition', 'intersects')

mesh = comp.mesh().create('mesh1', 'geom1')
mesh.create('ftri1', 'FreeTri')
sz = mesh.feature('ftri1').create('size1', 'Size')
sz.set('custom', 'on'); sz.set('hmax', '0.2[mm]'); sz.set('hmin', '0.01[mm]')
mesh.run()

solid = comp.physics().create('solid', 'SolidMechanics', 'geom1')
solid.selection().all()
fix = solid.feature().create('fix1', 'Fixed', 1); fix.selection().set([2])
load = solid.feature().create('bl1', 'BoundaryLoad', 1)
load.selection().named('top'); load.set('FA', ['0', '1e3[N/m^2]'])

std = jm.study().create('std1'); std.create('stat', 'Stationary')
model.solve()
print(model.evaluate('solid.mises', 'N/m^2'))
```
